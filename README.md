# Dr.BottleGourd24 - Bottle Gourd Leaf Disease Classification with CNN

This repository presents the research work associated with **Dr.BottleGourd24**, a deep-learning-based approach for automated bottle gourd leaf disease classification using Convolutional Neural Networks (CNN).

## 📌 Paper Information

**Title:** Dr.BottleGourd24-Bottle Gourd Leaf Disease Classification with CNN

**Presented at:** IEEE CS BDC Symposium 2024

**Volume:** 3

**Date:** November 22–23, 2024

## 🔬 About the Research

Plant diseases can significantly affect crop health and agricultural productivity. Early and accurate identification of leaf diseases can support better crop management and reduce potential losses.

This research focuses on the automated classification of bottle gourd leaf diseases using deep learning techniques.

A Convolutional Neural Network (CNN) is used to analyze leaf images and distinguish between healthy and diseased bottle gourd leaves.

## 🎯 Research Objective

The main objective of this research is to develop an automated image-based system for bottle gourd leaf disease classification.

The system aims to support:

- Early disease detection
- Automated plant health analysis
- Accurate classification of healthy and diseased leaves
- Reduced dependence on manual inspection
- AI-assisted agricultural monitoring
